# Infosys SP & DSE Preparation — Java and DSA

A structured preparation repository containing Java programming concepts, Data Structures and Algorithms, coding problems, and technical interview preparation for Infosys Specialist Programmer (SP) and Digital Specialist Engineer (DSE) roles.

## Repository Structure

- **`Java_Basics/`** – Core Java concepts, syntax, variables, data types, operators, conditions, and loops.
- **`OOP_Concepts/`** – Object-oriented programming concepts, including classes, objects, inheritance, polymorphism, abstraction, and encapsulation.
- **`Arrays/`** – Array traversal, searching, manipulation, and problem-solving techniques.
- **`Strings/`** – String operations, character processing, pattern matching, and string-based coding problems.
- **`Collections/`** – Java Collections Framework, including ArrayList, HashMap, HashSet, and other collection classes.
- **`Recursion/`** – Recursive problem-solving techniques and implementation.
- **`Searching_Sorting/`** – Searching and sorting algorithms with implementation and analysis.
- **`DSA_Patterns/`** – Common problem-solving patterns and their applications.
- **`Dynamic_Programming/`** – Memoization, tabulation, and optimization-based problems.
- **`Coding_Problems/`** – Practice problems focused on Infosys SP and DSE coding rounds.
- **`Interview_Preparation/`** – Technical interview questions, explanations, and coding discussions.

## Detailed Core Topics

### 1. Core Java Programming

- Java fundamentals, data types, variables, and operators.
- Conditional statements and looping constructs.
- Methods, constructors, and method overloading.
- Static variables, methods, blocks, and initialization.
- Exception handling and basic input/output operations.

### 2. Object-Oriented Programming

- Classes and objects.
- Inheritance and its types.
- Method overloading and method overriding.
- Encapsulation and abstraction.
- Constructors, `this`, and `super` keywords.
- Interfaces and abstract classes.

### 3. Data Structures

- **Arrays:** Traversal, insertion, deletion, searching, and manipulation.
- **Strings:** Character frequency, palindrome, anagrams, and string transformations.
- **Collections:** ArrayList, HashMap, HashSet, and common operations.
- **Stack and Queue:** Fundamental operations and problem-solving applications.

### 4. Algorithms & Problem-Solving

- Searching and sorting algorithms.
- Recursion and backtracking.
- Two-pointer and sliding-window techniques.
- Greedy algorithms.
- Dynamic programming using memoization and tabulation.
- Time and space complexity analysis.

### 5. Infosys SP & DSE Coding Preparation

- Basic programming and logical problems.
- Array and string-based coding questions.
- Mathematical and number-based problems.
- Advanced problem-solving and algorithmic questions.
- Coding practice with Java and standard input using `Scanner`.
- Problem explanation, logic development, and dry-run analysis.

   ```bash
   cd Infosys-SP-DSE-Preparation
   ```
