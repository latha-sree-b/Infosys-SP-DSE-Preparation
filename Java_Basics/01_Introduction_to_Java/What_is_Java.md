# What is Java?

## 1. Introduction

Java is a **high-level, object-oriented, class-based programming language** developed by **James Gosling** and his team at Sun Microsystems.

Java was initially released in **1995**. It is widely used to develop web applications, desktop applications, enterprise software, Android applications, and backend systems.

Java follows the principle:

> Write Once, Run Anywhere (WORA).

This means Java programs can run on different operating systems without changing the original source code, provided a compatible Java Virtual Machine (JVM) is available.

---

## 2. Why Java?

Java is popular because it provides:

- Platform independence.
- Object-oriented programming.
- Strong memory management.
- Automatic garbage collection.
- Multithreading support.
- Security features.
- Rich standard libraries.
- Exception handling.
- High performance through JIT compilation.

## 4. How Does Java Work?

Java programs follow a two-step execution process.

**Step 1: Compilation**

The Java compiler converts source code (`.java`) into bytecode (`.class`).

**Step 2: Execution**

The JVM executes the generated bytecode.

```text
Java Source Code
      |
      |  javac compiler
      v
Bytecode (.class)
      |
      |  JVM
      v
Machine Code
      |
      v
Program Output
```

### Example

**Java source code:**

```java
class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

**Compile:**

```bash
javac Main.java
```

**Execute:**

```bash
java Main
```

**Output:**

```text
Hello Java
```

## 7. Important Java Terminology

| Term | Meaning |
|---|---|
| JDK | Java Development Kit – tools required to develop Java applications. |
| JRE | Java Runtime Environment – runtime components for running Java applications. |
| JVM | Java Virtual Machine – executes Java bytecode. |
| Bytecode | Intermediate code generated by the Java compiler. |
| JIT | Just-In-Time compiler – compiles frequently executed bytecode into native machine code. |
| Garbage Collection | Automatic process of reclaiming memory occupied by objects that are no longer reachable. |

## 10. Important Interview Questions

**1. What is Java?**

Java is a high-level, class-based, object-oriented programming language designed to be platform independent through the JVM.

**2. Who developed Java?**

James Gosling and his team at Sun Microsystems.

**3. When was Java released?**

1995.

**4. Why is Java platform independent?**

Java source code is compiled into bytecode, which can execute on any platform with a compatible JVM.

**5. What is bytecode?**

Bytecode is the intermediate code generated by the Java compiler and stored in `.class` files.

**6. What is WORA?**

WORA stands for Write Once, Run Anywhere. It means Java bytecode can run on different platforms with a compatible JVM.

**7. Is Java purely object-oriented?**

No. Java supports primitive data types such as `int`, `char`, `boolean`, and `double`, so it is not considered purely object-oriented.

**8. Is Java compiled or interpreted?**

Java uses both approaches. The compiler generates bytecode, and the JVM executes it using interpretation and JIT compilation.
